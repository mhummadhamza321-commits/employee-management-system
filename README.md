# 👥 Employee Management System

A simple CRUD application to manage employee records, built with vanilla JavaScript using the MVC pattern and localStorage.

## 🚀 Live Demo

**[Click here to try it live](https://mhummadhamza321-commits.github.io/employee-management-system/)**

## ✨ Features

- ➕ Add new employees (name, email, role, salary)
- ✏️ Edit existing records
- 🗑️ Delete employees with confirmation
- 💾 Data persists in browser via localStorage
- 📱 Responsive design
- 🏗️ Clean MVC architecture

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- localStorage API

## 🏗️ Architecture

- **Model** — Data + localStorage persistence
- **View** — DOM rendering
- **Controller** — Binds user actions to Model/View
